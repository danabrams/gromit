# Bug Investigation: Status display data lost during architecture migration

## Symptom
`gromit status` shows minimal output — just raw status.json fields (iteration, bead, elapsed).
Missing: iteration progress (N/M), time budget, model, cost data, SPC metrics, health,
pipeline status, and next-action recommendation. The acceptance tests reference
`runner.PrintStatus` which does not exist.

## Root Cause
The architecture migration from monolithic `Runner` to Orchestrator + pipeline stages
removed the rich status display code without replacing it:

1. **`Runner.Status()` removed** — `lifecycle.go:122-213` orchestrated reading status.json,
   pipeline status, state files, model stats, and process trend, then formatted all sections.
   This method was deleted and never replaced with a standalone `PrintStatus` function.

2. **Formatting functions removed from `format.go`** — The current `format.go` only has
   `formatPipeline`/`formatItems`. The old version also had: `formatRun`, `formatRunningLine`,
   `formatDuration`, `formatHealth`, `formatModelPerformance`, `formatRecommendation`,
   `formatSPCSummary`, and all SPC helper functions (~200 lines removed).

3. **StatusWriter data gaps** — `constructor.go:182` passes `""` for model and `0` for
   timeBudgetMinutes. `epilogue.go:196` also passes `""` for model despite having
   `in.Result.Model` available.

4. **CLI stub** — `cmd/gromit/main.go:220-266` (`showStatus`) reads raw status.json fields
   instead of calling the rich `PrintStatus` that acceptance tests expect.

## Affected Code
- `internal/runner/format.go` — missing formatting functions
- `internal/runner/status.go` — Status struct (OK, no changes needed)
- `internal/runner/constructor.go:180-184` — StatusWriter callback passes empty model and 0 time budget
- `internal/pipeline/epilogue/epilogue.go:196` — passes empty model
- `cmd/gromit/main.go:220-266` — CLI command uses simplified display
- `internal/runner/acceptance/status_acceptance_test.go` — tests call nonexistent `PrintStatus`
- `internal/runner/acceptance/status_integration_acceptance_test.go` — same

## Suggested Fix
1. Restore formatting functions to `format.go` (from old worktree reference)
2. Implement `PrintStatus` as a standalone function (replaces `Runner.Status()`)
3. Update CLI `showStatus` to call `runner.PrintStatus`
4. Fix Epilogue status write to pass model from `in.Result`
5. Fix constructor StatusWriter callback to pass time budget from deadline

## Evidence
- Old `lifecycle.go` preserved in worktree `.-gromit-debug-1771735150064710899` shows full `Runner.Status()` at lines 122-213
- Old `format.go` in same worktree shows all formatting functions (~387 lines vs current ~76 lines)
- Acceptance tests (`status_acceptance_test.go`) expect: "Pipeline:", "Run: iteration 12/50", "of 30m elapsed", "Model: sonnet", "SPC: (no data)", "Health:", "Last retro:", "Last review:", "Next action:"
- Current `showStatus` in main.go only shows: "Status:", "Iteration:", "Bead:", "Model:", "Started:", "Elapsed:", "Max iterations:", "Time budget:"
