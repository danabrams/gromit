# Developer Experience

## Problem

The CLI workflow has friction points: decompose UX requires multiple commands, status shows limited info, plan picker doesn't indicate what's already planned, refine doesn't offer a blank-slate option, review doesn't track "since last review", and there's no Claude skill for orchestration.

## Vision

A polished CLI experience where each command is intuitive, shows relevant context, and chains naturally into the next step — reducing the cognitive load of driving the pipeline.

## Scope

- Decompose command UX improvements
- Plan picker showing already-planned specs
- Refine "something new" option
- Expanded gromit status display
- Manual review since last review
- Claude skill for gromit orchestration
- Git auto-push
- Preflight gates before bead execution
- Config consistency (precheck/verification)
